# Coronary-Artery-Segmentation
#  Coronary Artery Segmentation using U-Net

##  Overview
This project demonstrates image segmentation using a U-Net deep learning model.  
A synthetic dataset is generated using OpenCV to simulate coronary artery structures.

##  Model
- U-Net architecture
- Encoder-Decoder network
- Binary segmentation

##  Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib

##  Features
- Synthetic dataset generation
- Model training
- Prediction and visualization

##  Results
The model successfully segments circular regions (simulated arteries).

##  How to Run
1. Open in Google Colab
2. Run all cells
3. View output

## ⚠️ Note
This is a prototype project using synthetic data for demonstration purposes.
